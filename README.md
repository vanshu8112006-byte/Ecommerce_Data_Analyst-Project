
#**E-Commerce Sales & Customer Analytics**

**Project Overview:-**

This is a Python Data Analyst portfolio project based on E-Commerce transaction data.

The project analyzes sales, profit, customers, products, marketing channels, returns, discounts, and other business factors using Python.

**Objectives:-**

- Analyze total sales and profit
- Identify top-performing products and categories
- Analyze sales by city
- Understand marketing channel performance
- Analyze customer behavior
- Identify areas with high returns
- Study the impact of discounts
- Find useful business insights

**Tools & Technologies:-**

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

**Project Analysis:-**

**1. Data Cleaning**

- Removed duplicate records
- Handled missing values
- Cleaned data columns
- Prepared data for analysis

**2. KPI Analysis**

The project calculates:

- Total Sales
- Total Profit
- Total Orders
- Total Customers
- Average Order Value
- Profit Margin
- Return Rate

**3. Exploratory Data Analysis**

The project includes analysis of:

- Monthly Sales
- Category Performance
- Product Performance
- City-wise Sales
- Marketing Channels
- Returns
- Discounts
- Customer Analysis

**Visualizations:-**

The project uses:

- Line Chart
- Bar Chart
- Histogram
- Scatter Plot

**Business Insights:-**

The analysis helps understand:

- Which cities generate more revenue
- Which products and categories perform well
- Which marketing channels generate sales
- Where returns are high
- How discounts affect sales and profit
- Which customers are valuable or may need attention
